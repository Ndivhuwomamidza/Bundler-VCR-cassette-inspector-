1.
Introduction & Overview

We respect your privacy and are committed to safeguarding it. This Privacy Policy details the policies and procedures regarding the collection, handling, and non-retention of your data when using the Bundler VCR Cassette Inspector.

Our core principle is simple: we do not collect, monetize, sell, or profile your personal data or uploaded test recordings. The application is engineered as a client-side diagnostic workstation.

2.
Information We Do NOT Collect
Zero Data Harvesting Guarantee
We do NOT require user account creation, emails, or passwords to access the tool.
We do NOT collect payment card details or financial information.
We do NOT deploy advertising identifiers (IDFA, GAID) or cross-site tracking beacons.
We do NOT sell, lease, or distribute your network fixtures or uploaded cassette contents to third parties or AI training farms.
3.
Client-Side & In-Browser Processing

When you upload a ZIP archive or a raw used_cassettes.txt file to examine your Bundler VCR test records:

Local File Decompression: Files are unzipped and parsed exclusively in your computer's browser process using JavaScript libraries (JSZip).
No Server Upload: The raw file content never leaves your browser sandbox. No HTTP POST or PUT payload containing your files is sent to our servers.
Immediate Eviction: If you close the browser tab or click "Reset to Official Artifact", the uploaded in-memory dataset is discarded from volatile browser RAM.
4.
Cookies & Local Storage

We do not use HTTP tracking cookies. We utilize standard browser Local Storage (localStorage) strictly for client-side configuration:

Key	Storage Type	Purpose	Duration
gsc_verification_code	localStorage	Stores user-entered Google Search Console verification token for meta-tag injection	Until cleared by user

You can clear this storage at any time using your browser's Developer Tools (Application > Storage > Clear site data).

5.
Service Worker & Offline Caching

The Application implements a Progressive Web App (PWA) service worker (/sw.js). This script caches static application assets (HTML, JavaScript bundles, CSS stylesheets, icons, and the default Bundler sample dataset) in your browser's Cache Storage API so the tool can function offline in air-gapped environments.

6.
Cloud Hosting & Technical Server Logs

The static web assets are served via Google Cloud Run infrastructure. Like standard internet hosting providers, basic non-identifying server request logs (such as IP address, user-agent string, timestamp, and requested URL) are automatically generated by the web hosting layer for server security, DDoS defense, and technical availability monitoring.

7.
Google Search Console & Third-Party Integrations

The application provides an interactive SEO & Google Search Console verification hub. If you configure a custom site verification token, it is inserted into the active HTML DOM on your local instance. No private credentials or Google user tokens are accessed or required.

8.
Data Security Architecture

All communications between your browser and our hosting infrastructure are encrypted using transport layer security (HTTPS / TLS 1.3). Because all file analysis is executed within your browser's client-side runtime, your proprietary test code, credentials, and cassette recordings are never exposed across public networks.
